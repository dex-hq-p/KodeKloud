# Requirement Analysis Workflow

1. **Solution Architect**: làm rõ mục tiêu, scope, NFR, domain và trade-off.
2. **Backend/Frontend/DBA/DevOps**: đánh giá ảnh hưởng theo từng boundary.
3. **Code Reviewer**: kiểm tra tính đầy đủ, rủi ro và acceptance criteria.
4. Ghi lại quyết định, open questions, dependency và definition of done.

Output: requirement đã được làm rõ, design note ngắn và danh sách implementation task.
