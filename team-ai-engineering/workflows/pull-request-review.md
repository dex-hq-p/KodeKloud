# Pull Request Review Workflow

1. Đọc issue, acceptance criteria và diff.
2. Chạy checklist trong `skills/code-review/SKILL.md`.
3. Xác minh test, migration, config, security và backward compatibility.
4. Ghi finding theo mức độ; yêu cầu sửa blocker/major trước approval.
5. Xác nhận CI và để lại summary ngắn về phạm vi đã kiểm tra.
