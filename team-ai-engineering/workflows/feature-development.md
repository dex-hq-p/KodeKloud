# Feature Development Workflow

1. Phân tích issue và chốt contract.
2. Backend/Frontend/DBA/DevOps triển khai vertical slice tương ứng.
3. Thêm unit/integration/e2e test theo risk.
4. **Code Reviewer** review diff, security và vận hành.
5. Chạy CI, cập nhật tài liệu, release note và rollback plan.

Definition of done: behavior đúng, test xanh, observability đủ và PR được approve.
