# Spring Boot Development

- Đọc module/package tương tự và convention trước khi tạo abstraction mới.
- Giữ validation, authorization, error mapping, transaction và persistence ở layer phù hợp.
- Thêm test cho happy path, validation, authorization và failure modes liên quan.
- Chạy test/build mục tiêu; không đưa credential thật vào cấu hình.
