# React Development

- Đọc component tương tự, design system và API contract hiện có.
- Giữ component nhỏ, state rõ ràng và accessibility; không thay đổi API/domain semantics ở UI.
- Thêm hoặc cập nhật test cho tương tác mới; chạy ESLint/test liên quan nếu đã cấu hình.
- Không chạy formatter/linter trên toàn repo khi chỉ cần kiểm tra file thay đổi.
