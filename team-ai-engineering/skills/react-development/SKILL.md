# React Development Skill

- Dùng TypeScript strict và component có interface props rõ ràng.
- Tách server state, UI state và form state; tránh global state không cần thiết.
- Mọi async view có loading, empty, error và retry state phù hợp.
- Dùng semantic HTML, keyboard navigation và accessible labels.
- Test bằng user behavior và mock API ở boundary.
