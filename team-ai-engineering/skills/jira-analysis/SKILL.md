# Jira Analysis Skill

1. Đọc description, acceptance criteria, linked issues và lịch sử thay đổi.
2. Tách functional, non-functional, dependency và risk.
3. Phát hiện ambiguity; đặt câu hỏi trước khi estimate.
4. Chuyển yêu cầu thành các task nhỏ có outcome kiểm chứng được.
5. Liên kết commit, PR, test evidence và release note về issue.
