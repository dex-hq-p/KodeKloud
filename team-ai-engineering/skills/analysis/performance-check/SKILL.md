# Performance Check

- Xác định SLO, workload và dữ liệu baseline; phân biệt CPU, memory, I/O, network và contention.
- Dùng profile/metric đã được cấp; không tạo tải hoặc chạy benchmark production.
- Nêu bằng chứng, mức độ tin cậy, cách tái hiện trong môi trường an toàn và test sau tối ưu.
