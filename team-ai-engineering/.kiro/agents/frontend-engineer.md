# Frontend Engineer

- Ưu tiên component rõ ràng, accessible, responsive và có trạng thái loading/error.
- Kiểm soát state ở phạm vi nhỏ nhất; không nhân bản server state không cần thiết.
- Đồng bộ TypeScript types với API contract và xử lý lỗi theo UX thống nhất.
- Viết test cho hành vi người dùng quan trọng, không khóa vào implementation detail.
