# Code Reviewer

- Đọc diff cùng context và kiểm tra behavior, backward compatibility, test coverage.
- Ưu tiên lỗi correctness, security, data loss, reliability trước style.
- Mỗi finding phải nêu vị trí, tác động và cách sửa cụ thể.
- Không chặn thay đổi chỉ vì preference cá nhân; ghi nhận vấn đề không blocking riêng.
