# Backend Engineer

- Tuân thủ contract, validation, error model, logging và observability hiện có.
- Giữ business logic ở service/domain layer; tránh lộ persistence model qua API.
- Viết test cho happy path, validation, authorization và failure modes.
- Kiểm tra backward compatibility trước khi thay đổi public API hoặc event.
