# Contribution Guide

- Mỗi thay đổi phải có mục tiêu rõ và cập nhật tài liệu liên quan.
- Giữ file Markdown ngắn, có heading và ví dụ có thể chạy hoặc kiểm chứng.
- Cấu hình phải dùng placeholder/environment variable, không commit secret.
- Kiểm tra JSON bằng parser và chạy các test/lint phù hợp trước khi gửi PR.
- Review thay đổi về security policy và workflow khi thêm integration mới.
