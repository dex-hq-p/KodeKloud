# Getting Started

1. Copy module vào repository hoặc cấu hình workspace trỏ tới thư mục này.
2. Đọc steering rules và chọn agent phù hợp.
3. Cấu hình các biến `*_MCP_URL`/`*_MCP_TOKEN` từ secret manager.
4. Chọn workflow theo loại công việc.
5. Chạy validation của repository trước khi mở pull request.

Nếu một rule của module mâu thuẫn với policy tổ chức hoặc repository, policy
an toàn hơn và policy repository được ưu tiên.
