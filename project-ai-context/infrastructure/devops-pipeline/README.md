# DevOps Pipeline Context

Đặt context và runbook cho Kubernetes, Bitbucket Pipeline, Nginx và cấu hình triển khai tại đây. Dùng [runbook template](../../_templates/infrastructure-template/runbook-template.md).

Chưa có cấu hình cluster/pipeline cụ thể được xác minh trong context hiện tại. Không suy diễn resource limit, lịch chạy hoặc trạng thái runtime.
